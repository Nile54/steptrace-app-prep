## Featured project: Origin Scholar

[Origin Scholar](https://originscholar.pages.dev) (formerly StepTrace) is a local-first application-preparation tool: link tasks to exact instructions, review source changes and dependent work, and preserve completion history.

An **AI-assisted personal project**, with deterministic matching, cycle-checked dependencies and validated JSON backup/restore. The application does not use an AI model or decide eligibility.

[Try the fictional demo](https://originscholar.pages.dev) · [Source and setup](https://github.com/Nile54/steptrace-app-prep) · [Architecture](https://github.com/Nile54/steptrace-app-prep/blob/main/docs/ARCHITECTURE.md) · [Evaluation](https://github.com/Nile54/steptrace-app-prep/blob/main/docs/EVALUATION.md)

Automated engineering checks cover source links, review histories and recovery. Human evaluation is pending; usefulness and accessibility benefit have not been established.
