# Sources, related work and working name

StepTrace applies established traceability ideas to a small, human-controlled application-preparation workflow. The consumer workflow is a hypothesis to evaluate, not a verified invention, exclusive feature or market gap. No affiliation with the products below is implied.

## Traceability prior art

- [IBM DOORS: Suspect links and changed objects](https://www.ibm.com/docs/en/engineering-lifecycle-management-suite/doors/9.7.2?topic=data-suspect-links-changed-objects) describes how changes to linked objects can make relationships suspect and how people inspect and clear those links. The official indexed page was reviewed September 22, 2026; direct retrieval returned an access error in the release research tool.
- [Jama Connect: Clear suspect links](https://help.jamasoftware.com/en/manage-content/coverage-and-traceability/relationships/clear-suspect-links.html) describes downstream suspect relationships after upstream changes and manual clearing after assessing impact or making changes. Reviewed September 22, 2026; the page labels its last modification September 18, 2024.

These sources establish conceptual overlap. StepTrace's implementation and fictional evaluation do not demonstrate superiority, feature exclusivity or interoperability with either system. Completion history, exact source versions, consumer task wording and unresolved human choices are this project's design decisions, documented in [ARCHITECTURE](ARCHITECTURE.md).
